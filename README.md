# photo2mesh

This local web app lets users upload photos, generate object masks, and reconstruct 3D PLY meshes with SAM3D in a WSL-based workflow.

It is designed to convert image input into structured 3D geometry using segmentation and mesh reconstruction pipelines.

写真をアップロードし、WSL 内の `sam3d-blackwell` conda 環境で SAM3D を実行して PLY モデルを生成するローカル Web アプリです。
